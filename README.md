One short funny line for make.fun's "One-Liner Laugh Lab" bounty: the excuse a robot vacuum gives after eating a sock. A single Python program (standard library only) writes the line to `/output/entry.txt`, deterministically, with no network access.

## Run it

```sh
python3 main.py
```
